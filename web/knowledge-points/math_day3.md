# 数学 Day 3 - 数据的表示和分析（三）

## 学习目标
学会用数据研究社会问题（小学六年级上册）

## 知识要点

### 主要概念
1. **用数据研究社会问题**：如人口老龄化
2. **数据收集**：从人口普查等官方渠道获取数据
3. **数据整理**：将原始数据整理成表格
4. **数据分析**：通过对比数据发现趋势

### 数据收集要点
1. **数据来源**：全国人口普查数据（第五、六、七次）
2. **数据类型**：
   - 老年人口数量（60岁及以上、65岁及以上）
   - 各年龄段人口占比

### 数据整理方法
1. **表格整理**：将数据整理成表格形式
2. **分类统计**：按年龄段分类统计
3. **计算占比**：计算各年龄段占总人口的比例

### 例题解析
**题目**：分析第五、六、七次全国人口普查数据，研究人口老龄化趋势。

**数据示例**：
- 第六次普查：60岁及以上177648705人
- 第七次普查：60岁及以上264018766人

**分析步骤**：
1. 计算老年人口数量的增长
2. 计算老年人口占比的变化
3. 分析人口老龄化趋势

### 学习方法
1. 提出要研究的问题
2. 收集相关数据
3. 整理成表格
4. 分析数据得出结论
