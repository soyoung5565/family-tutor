# 数学 Day 1 - 分数的应用（一）

## 学习目标
掌握"求一个数的几分之几是多少"的实际应用（小学六年级上册）

## 知识要点

### 主要概念
1. **分数的应用**：用分数乘法解决生活中的问题
2. **单位"1"的量**：作为基准的量
3. **分率**：表示部分与整体关系的分数

### 核心公式
```
求一个数的几分之几是多少，用乘法计算：
数量 = 单位"1"的量 × 分率
```

### 例题解析（小学生能理解的例子）
**题目**：气象小组有12人，摄影小组的人数是气象小组的1/3，航模小组的人数是摄影小组的3/4，求航模小组的人数。

**解题步骤**：
1. 先求摄影小组的人数：12 × 1/3 = 4人
2. 再求航模小组的人数：4 × 3/4 = 3人

**答**：航模小组有3人。

### 练习题
1. 假设科技小组有15人，音乐小组的人数是科技小组的2/5，美术小组的人数是音乐小组的4/5，求美术小组的人数。

### 易错点
1. 要分清谁是单位"1"的量
2. 连续求几分之几时，要一步一步计算
3. 注意分数乘法的计算方法

### 学习方法
1. 先读题，找出已知条件
2. 确定单位"1"的量
3. 列式计算
4. 检验答案是否合理
