# 家庭教师系统 · 全流程结构（2026-09-26 版）

> 本文是系统全景图：数据底座 → 日常闭环 → 订正支线 → 周末线 → 工具运维。
> 状态文件：`系统/学习状态.json`、`系统/学习规划.md`、`系统/周计划状态.json`

---

## 0. 总览图

```
【学生/家长】拍照作业 ─────────────┐
                                   ▼
 ┌─────────────────────────────────────────────────────────┐
 │ ① 批改 + 分析（Day-1 三件套 · day1-pipeline.py）          │
 │    grade-mistake.py（火山vision+LLM：题目/作答分离提取→    │
 │    独立求解→判卷→候选KP→匹配KP库）                        │
 │        ↓                                                 │
 │    ①-1 知识点漏洞分析 → 学习状态.json（master/连错/错因） │
 │    ①-2 学校进度判定（classify-homework 信号；防抖+冷却）   │
 │        → 周模式（预习/单元复习/期中期末）                  │
 │    ①-3 错题入库 → 科目/错题集/错题集_YYYY-MM.json        │
 │    → 自动刷新 学习规划.md（周计划）                        │
 └─────────────────────────────────────────────────────────┘
                │（批改完立即：文字清单发给家长/孩子 → 自动生成课堂）        │
                ▼
 ┌─────────────────────────────────────────────────────────┐
 │ ② 微课生成链（错题讲解 · 流程默认步骤）                    │
 │    错题文字清单（学生版·无答案）→ micro-lesson.py 自动生成 │
 │    → OpenMAIC（直连火山）→ 课件 + TTS                    │
 │    订正回流时：collect-corrections.py → micro-publish.py  │
 │    （决定 reuse / regenerate / skip）→ 重生成只覆盖未订正   │
 │    工具：edit-micro-lesson.py（剪裁场景）、tts-backfill.py │
 └─────────────────────────────────────────────────────────┘
                ▼
 ┌─────────────────────────────────────────────────────────┐
 │ ③ 周末线                                                 │
 │    generate-weekly-plan.py（周计划：模式+每日安排+回灌）   │
 │    day-schedule.py（中途进入：今天+剩余每天+明天再来）     │
 │    generate-exam.py（5 种卷：模拟/默写/错题回灌/听写/背诵）│
 │    出题优先：错题集原题（每周≥1道）> 题库同类题 > 新题     │
 └─────────────────────────────────────────────────────────┘
                ▼
 ┌─────────────────────────────────────────────────────────┐
 │ ④ 触发机制（不用 cron）                                   │
 │    time-inject-hook.py（每轮对话注入时间）                 │
 │    （周一 Hermes 备份提醒仅开发机用；家长端不需要备份）     │
 │    └ 跨周：检查家教周计划是否需更新（读 周计划状态.json）   │
 └─────────────────────────────────────────────────────────┘
```

## 1. 数据底座
| 资产 | 位置 | 现状 |
|---|---|---|
| 知识点库（三科） | `科目/知识点及掌握情况/`（kp json + index） | 数学 61 / 语文 54 / 英语 26 KP |
| 题库 | `科目/测验/` | 数学 5668 / 语文 3746 / 英语 2855 题（已审计） |
| 课本材料 | `科目/课本/` | 扫描版 + 提取文本 |
| 知识要点文档 | `科目/知识点及掌握情况/*.md` | 学习/规划文档 |

## 2. 学情状态（AI 负责建立与维护）
| 文件 | 作用 | 维护时机 |
|---|---|---|
| `系统/学习状态.json` | KP 状态机（master/attempts/连错/错因）+ 周模式 + 错题最近记录 + 信号日志 | 每次批改/三件套后 |
| `系统/学习规划.md` | 学生/家长视图：模式横幅 + 学期总览 + 每周计划 | 周计划刷新时 |
| `系统/周计划状态.json` | hook 触发标记（last_generated） | 每次生成周计划后 |
| `科目/错题集/错题集_YYYY-MM.json` | 错题本（题目+作答+KP+错因） | 每次入库 |

## 3. 脚本清单（系统/scripts/）
- 批改与流水线：`grade-mistake.py`（火山接线版）、`day1-pipeline.py`（三件套编排）
- 进度与计划：`classify-homework.py`（信号/模式）、`generate-weekly-plan.py`、`init-learning-state.py`、`day-schedule.py`（中途进入剩余安排）
- 微课链：`micro-lesson.py`、`micro-publish.py`、`collect-corrections.py`、`verify-micro-lesson.py`
- 编辑工具：`edit-micro-lesson.py`、`tts-backfill.py`
- 出卷：`generate-exam.py`（5 种卷）
- 题库建设：`quiz-bank-search.py`、`vote-judge*.py`、`ingest-exam.py` 等

## 4. 服务与外部依赖
| 服务 | 端口/位置 | 宿主 |
|---|---|---|
| OpenMAIC 课堂服务 | :3000 | schtasks `FamTutorOpenMAIC` |
| MIMO TTS 代理 | :8787 | schtasks `FamTutorTTS` |
| new-api 网关（备用） | 13000/13002 | 看门狗托管 |
| 火山方舟（主力） | ark plan 端点 | 直连（视/文/微课都用它） |
| 周计划/备份触发 | hooks.pre_llm_call | time-inject-hook.py |

## 5. 开发 vs 使用
- 开发期：状态文件可空/停更（允许）；测试数据可入 dev 状态。
- 上线后：**每次处理作业必须完成三件套更新**（见 skill 0.3/0.4 条款）；微课为可选分支。
