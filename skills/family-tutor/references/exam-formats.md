# 试卷形式规范（2026-09-12 起执行）

## 0. 总览：5 种形式

| 形式 | 文件输出 | 适用场景 | 出题规则 |
|---|---|---|---|
| 题目卷 | PDF + Word | 单元复习 / 期中 / 期末 | KP 全覆盖 + 难度按 KP 掌握度加权 |
| 默写卷 | PDF + Word | 字词默写、课文默写、单词默写 | 挖空 + 错字回灌 |
| 错题回灌卷 | PDF + Word | 每周模拟卷必含 | 从错题集抽 1–2 道同类题 |
| 听写包 | MP3 + Word 答案 | 英语单词、语文生字 | TTS 生成音频 + 答案文本 |
| 背诵检查表 | Word | 课文背诵检查 | 填空自检，不算"题" |

**用户原话**：「试卷的形式也不应该只被试卷所束缚。例如学生的语文本周一直在错某个字或某篇诗没背好。或是英语某个单词一直错。试卷也可以以默写等其他形式，不一定非得是出题目。」

---

## 1. 题目卷（最常见形式）

### 1.1 触发
- 单元复习：每周日生成下周计划时检测到"单元复习"信号 → 出单元复习卷
- 期中/期末：识别到"期中复习 / 期末复习"作业 → 出混搭卷
- 定时复盘：每月一次全 KP 大复盘

### 1.2 出题规则

**单元复习卷**
- KP 覆盖：本单元所有 KP（6–10 个）
- 难度分布：易 50% + 中 35% + 难 15%
- 题型：按 KP 类型自动选（计算题→计算，拼音→拼音等）
- 题量：单科 15–25 道（6 年级一节课内能做完）
- 错题回灌：从错题集抽 1 道同 KP 的题（如果该 KP 有错题）
- 时长标注：每卷末尾写"建议用时 X 分钟"

**期中 / 期末卷（混搭）**
- KP 覆盖：考试范围内的全部 KP（如期中考前 4 单元）
- 难度分布：易 30% + 中 50% + 难 20%
- 题量：单科 30–40 道（模拟真实考试节奏）
- 错题回灌：从错题集抽 2 道薄弱 KP 的题
- 时长标注：建议 90 分钟

**题目卷结构（强制）**
```
一、基础题（易）   —— 拼音/字词/单词
二、应用题（中）   —— 句子改写/句型转换/计算题
三、提升题（难）   —— 阅读理解/应用题/习作
```

### 1.3 输出格式

**PDF**（用 reportlab 生成，打印最干净）
- A4 纸
- 标题居中：「六年级 {科目} {范围} 复习卷」
- 学生信息栏：姓名 / 班级 / 学号 / 日期
- 每题标难度（易 / 中 / 难）便于老师审
- 末尾"参考答案"独立页（可拆）

**Word**（用 python-docx 生成，老师可改）
- 同 PDF 排版
- 留出答题空间（填空题下空一行、写作题给 5×10 空格）

### 1.4 文件命名
```
D:/家教/{科目}/试卷/
  ├── unit_{N}_{date}.pdf
  ├── midterm_2026_11.pdf
  ├── final_2027_01.pdf
  └── weekly_2026-09-15.pdf
```

## 2. 默写卷（语文字词/课文 + 英语单词/句型）

### 2.1 触发
- 学生近期同一字/词错 ≥ 3 次
- 单元复习周的"字词基础"模块
- 课文/单元要求背诵段落

### 2.2 挖空规则

**语文**
- 生字：给出拼音 + 挖字（学生写汉字）
- 词语：给出一半字 + 挖空一半
- 古诗：挖关键词（如"万重山"挖"重"，或整句挖空）
- 课文段落：挖关键短语（不挖整句，避免无意义默写）

**英语**
- 单词：中文释义 + 挖单词
- 短语：挖 1–2 个关键词
- 句型：挖需要掌握的核心结构（如 be able to 句型挖 be able to）

### 2.3 错字回灌（重要）
- 学生最近错过的字/词 → 必须在默写卷出现 1 次（降低再错概率）
- 错字来源：D:/家教/{科目}/错题集/mistake_*.json 里的 kp_id + stem 字段

### 2.4 输出
- PDF：挖空版（学生用） + 答案版（家长用） = 2 个文件
- Word：同上

### 2.5 文件命名
```
D:/家教/{科目}/试卷/
  └── dictation_{unit}_{date}.pdf
  └── dictation_{unit}_{date}_answer.pdf
```

## 3. 错题回灌卷

### 3.1 触发
- 每周必出：每周日生成下周计划时附带 1 道
- 学生某 KP 错 ≥ 3 次：立即生成 3 道同类题专项

### 3.2 同类题匹配
- 首选：从题库找同 KP 不同 qid 的题（避免重复）
- 次选：题库没有 → LLM 改写原错题（数字/情境替换，考点不变）
- 保底：原错题重做一遍（加深记忆）

### 3.3 出题规则
- 题量：1–3 道（不像正式卷那么多）
- 难度：根据错题原难度 +1（如原题"中"→ 这次出"中"或"难"）
- 解析必须显式引用"学生上次错的点"作为前置说明

### 3.4 输出
- PDF + Word
- 标题：「错题回灌 - {KP 名称} - {日期}」
- 每题首行标「上次错在：……」

## 4. 听写包（英语单词 + 语文生字）

### 4.1 触发
- 英语单元复习周必出
- 语文生字复习
- 学生某词/字反复错

### 4.2 听写包内容
```
D:/家教/{科目}/听写包/
  ├── listen_2026-09-15.mp3
  ├── listen_2026-09-15_answer.docx
  └── listen_2026-09-15_score.csv
```

### 4.3 TTS 实现
- 英语：用 MIMO TTS（参考 mimo-tts-asr.md），生成英文单词音频
- 语文：用 TTS 读生字（标准普通话）+ 单独一轨读拼音
- 语速：英语单词 0.7 倍速（学生记录用），语文生字 0.8 倍速
- 间隔：单词之间 5 秒（学生有时间写）

### 4.4 出题规则
- 每包 20–30 个词/字
- 错词回灌：学生最近错过的 ≥ 3 次的词必出
- 来源：题库 by-type/单词拼写.json 或 by-type/字音字形.json

## 5. 背诵检查表

### 5.1 触发
- 单元复习周
- 期中/期末前

### 5.2 内容（不算"题"）
```
课文背诵检查表 - 六年级语文上册 - Unit 1
日期：____   家长签字：____

□ 第 1 课《草原》第一段    （要求背诵/默写）
□ 第 2 课《丁香结》全文    （要求背诵/默写）
□ 古诗《宿建德江》         （要求背诵/默写）
...

备注（哪些段落卡壳、需要多背几遍）：
_______________________________________
```

### 5.3 输出
- 仅 Word（不打印 PDF）
- 文件命名：recite_{unit}_{date}.docx

## 6. 周计划自动出卷规则（关键）

**每周日 22:00 自动跑** generate-weekly-exam.py：

1. 读取 学习状态.json → 取所有 KP 的 master 值
2. 识别本周模式（预习 / 复习 / 期中 / 期末）
3. 按模式调用对应生成器：
   - 预习周 → 不出卷（课后习题从题库现抽）
   - 单元复习周 → 出题目卷（单科 15–25 道）
   - 期中周 → 出混搭卷（单科 30–40 道）
   - 期末周 → 出混搭卷（全 KP）
4. 错题回灌：自动追加 1–2 道错题集同类题
5. 输出到 D:/家教/{科目}/试卷/ 下，文件名带日期
6. 在 学习规划.md 里写"本周作业清单"一节

---

## 7. 试卷质量门

每张卷子生成后，AI 必须自检：

- 难度分布符合 §1.2 表格
- KP 覆盖完整（每单元/期中考前所有 KP 都至少 1 题）
- 错题回灌题已含
- 答案页齐全
- 题型符合 quiz-system-design.md 规则（拼音用选择不填空等）
- 字数/题量合理（不超过学生单次能完成的量）
