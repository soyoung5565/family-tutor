# 题库设计规范（2026-09-12 起执行）

## 0. 题库在整个闭环里的角色

题库不是「日常答题」用的（日常答题环节 = 学生拍照/输入 → AI 即时讲，详见 `quiz-system-design.md`）。
**题库只服务两个场景**：

1. **新预习课的课后习题**（学生预习完一个 KP → 从题库抽 1–3 道做课后练习）
2. **模拟卷生成**（单元复习 / 期中 / 期末 / 错题回灌 → 从题库按 KP 覆盖矩阵 + 难度分布抽题）

题源 = **真题优先（深圳本地 > 广东省 > 其他版本 > 名校卷 > LLM 生成）**。
数学因为结构化强，LLM 兜底占比可以高（≥ 60%）；语文英语必须以真题为主（≥ 60%），LLM 兜底只用于补缺口。

## 1. 题库目录结构（按 KP 二级索引）

```
D:/家教/{科目}/测验/
├── index.json                      # 题库总索引（题量、KP 覆盖矩阵、按难度分布）
├── u1/
│   ├── u1.k1.json                  # 该 KP 的所有题（数组）
│   ├── u1.k2.json
│   └── ...
├── u2/
│   └── ...
├── by-type/
│   ├── 拼音.json                   # 跨 KP 同题型聚合（出默写/听写时用）
│   ├── 字词.json
│   ├── 句子理解.json
│   ├── 阅读片段.json
│   ├── 习作片段.json
│   └── ...
└── _meta/
    ├── source-sites.json           # 真题来源网站清单（含访问方式 / VIP 状态）
    ├── cross-version-rules.json    # 跨版本判定记录（哪个版本号对应哪套 KP 范围）
    └── extraction-log.md           # 每次入库的人工/AI 审计日志
```

**每 KP 文件 = 该 KP 全部候选题（不再按难度分子文件，难度作为字段）。** 简单结构便于检索。

## 3. 题型枚举（按科目）

### 语文

## 4. 难度标定规则（AI 自动）

AI 综合以下 5 个维度标「易/中/难」，**不需要人工标**：

| 维度 | 易 | 中 | 难 |
|---|---|---|---|
| **题型复杂度** | 选择 / 填空 / 默写 | 句子改写 / 简答 | 篇章理解 / 习作 / 多步应用题 |
| **认知层级**（布鲁姆） | 记忆 / 理解 | 应用 / 分析 | 评价 / 创造 |
| **信息密度** | 1 个知识点 | 2–3 个知识点 | 4+ 知识点或跨单元 |
| **数字范围**（数学） | 整数 / 一位数小数 | 分数 / 二位数小数 | 负数 / 比例 / 复杂分数运算 |
| **干扰项设计** | 明显错误 | 接近但可辨 | 易混淆（需细致辨析） |

**难度标定示例**：
- 「渚读音选择题」 → 易（记忆 + 选择 + 单 KP）
- 「分数除法应用题（含 2 步推理）」 → 中
- 「圆与扇形组合面积 + 比例转换」 → 难

## 5. AI 自审清单（每题入库前必跑，不可省）

AI 必须按以下 5 项**逐条**自审，全部通过才能 `passed=true`：

### 5.1 考点对照
- **方法**：把题目的实际考点（做了什么、考了什么）与 KP 的 `definition` + `key_points` 对照
- **判定**：考点完全落在 KP 范围内 → ✓；引入 KP 范围外的新概念 → ✗
- **跨版本**：考点属于本教材六年级通用范围，但题目本身源自其他版本（如人教版/苏教版），只要 KP 覆盖即可入库，标 `cross_version.applicable=true`

### 5.2 超纲判定（最严格）
**触发以下任一即判超纲**：
- 涉及七年级/初中概念（负数、方程、函数、几何证明等 — 但注意：六上北师大版本身就有负数入门 u5，需 case-by-case）
- 数字过大或题型超出六年级课标
- 引入超前公式（如鸡兔同笼、牛吃草问题等奥数专属）
- 英语出现非课标词汇（超出六年级 800 词表）

**KP 范围内但题型变难是 OK 的**（如数学应用题数字变大、阅读题篇幅变长）。

### 5.3 年级情境
- 字数 / 段落长度 / 词汇难度符合六年级水平
- 不出现初中/高中才接触的修辞手法（比喻/拟人/排比 OK；通感/象征/反讽等需 KP 明确要求）
- 数学数字大小合理（分数不超过三位数百分比、整数运算不超 4 位数）

### 5.4 答案正确性
- AI **独立重做一遍**，答案与原题答案一致
- 不一致 → 标记 `answer_correct=false` + 写明差异，退回不入库
- 简答题/阅读理解答案需包含「答题要点」而非完整答案，便于 AI 批改时灵活判分

### 5.5 解析质量
- 解析不只是「答案=X」，要说**思路**（这道题考什么 / 关键步骤 / 易错点）
- 引用 KP 定义或 key_points 中的原话作为依据

**自审失败的题不删，保留并标 `enabled=false`**，入 `_meta/extraction-log.md` 记录失败原因，方便后续人工复核或换 KP 重试。

## 6. 跨版本判定 SOP（关键）

**用户原话**：「主要是内容要对，不一定要教材对…只要仔细甄别每道题有没有脱离本教材的考点或者说超纲就行。」

**判定流程**：

```
题目（任意版本）
  ↓
[1] 提取题目考点（AI 读题，列出 1–3 个核心考点）
  ↓
[2] 在本教材 KP 索引中查找覆盖
  - 命中 1 个 KP → 标 kp_id，写入
  - 命中多个 KP → 选主要那个，标 cross_version.also_covers=[...]
  - 不命中 → 标 enabled=false，记入 log
  ↓
[3] 检查方法/顺序差异
  - 纯方法/顺序差异（不影响考点）→ 入库，标 cross_version.applicable=true
  - 涉及超前方法（如方程解题而本教材用算术）→ 入库但降难度 + 备注「方法超出本教材范围」
  ↓
[4] AI 自审清单 5 项
```

**典型可入库存档**：
- 深圳/广州/上海/北京 各版本六上同一篇古诗的默写题 → 统编版 KP 直接入库
- 北师大版「圆的面积」题 → 任何版本六上都学圆，可入库
- 苏教版「分数除法」应用题 → 北师大版 u1 分数除法覆盖，可入库
- 人教版「百分数」题 → 北师大版 u6 百分数应用覆盖，可入库

**典型需 reject**：
- 七年级方程题用算术包装但本质是方程
- 含英语初中语法（宾语从句、现在完成时）

- 复习周/期中前重点 KP 要 10+ 道

## 9. LLM 兜底出题规范

当某个 KP 搜不到 6 道以上真题时，启用 LLM 兜底：

- **强制 prompt 模板**：
  - 必须包含该 KP 的 `definition` + `key_points` + `common_mistakes`
  - 必须包含「六年级 {学科} {版本}」约束
  - 必须包含「参考真题示例」（同 KP 已有真题作为风格参考）
  - 输出 JSON 必须符合 §2 schema，且 `source.is_real_paper=false`、`source.site="llm_generated"`
- **同样要跑 §5 自审清单**，LLM 自审自身出题
- **抽样人工核**：LLM 生成题每 10 道至少人工抽 2 道核对
- **强制标注**：所有 LLM 生成题 `qid` 加 `.g` 后缀（如 `yuwen_u1_k1_easy_001.g`）便于识别

## 10. 质量门（任何题入库前最后一道关）

入库前必须满足：

- [ ] `self_review.passed=true` 且 5 项全 ✓
- [ ] 答案独立验证过
- [ ] 解析含思路不只答案
- [ ] 来源信息完整（URL 可点开至少能看题）
- [ ] 跨版本题已注明 `cross_version.reason`
- [ ] LLM 生成题已抽检

不满足 → 退回修改或废弃。

---

## 11. 维护规则

- **题库有保质期**：真题用过 3 次后必须人工检查是否还合用（教材小调整、课标变化）
- **错题回灌**：学生错过的同类题（同一 KP 不同 qid）标 `use_count+=1`，帮助识别哪些题效果好
- **定期清理**：半年一次，`enabled=false` 且 `use_count=0` 的题移到 `_meta/archived/`
- **跨设备同步**：题库 JSON 走 Git 私有仓库管理（参考 memory: Git D 盘 repo）
