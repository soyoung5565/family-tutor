# OpenMAIC IndexedDB vs File System Import Workflow (2026-07-10)

## Critical Discovery

**OpenMAIC homepage "最近学习" list reads from IndexedDB, NOT from the file system.** This is the most important pitfall for API-generated courses.

## The Problem

When you use `/api/generate-classroom` to generate courses, the output JSON is written to:
```
D:\projects\OpenMAIC\data\classrooms\{classroomId}.json
```

But the homepage `listStages()` function reads from **IndexedDB** (browser-side Dexie database). The homepage will NOT show your API-generated courses unless you explicitly import them.

## Root Cause

OpenMAIC uses dual storage:
- **File system**: `D:\projects\OpenMAIC\data\classrooms\*.json` (generated by API)
- **IndexedDB** (Dexie): `db.stages`, `db.scenes`, `db.mediaFiles` (read by homepage)

These two are NOT automatically synchronized. The file system is the "raw" storage, IndexedDB is the "display" storage.

## Symptoms

- User sees 3 courses (previously generated manually in browser)
- But 7 courses exist in `D:\projects\OpenMAIC\data\classrooms\`
- Homepage only shows 3, not 7
- User: "课件生成完了但主页看不到" / "我这里只有那三个课件啊"

## Solutions

1. Run the packing script:

   This creates ZIP files in `D:\projects\family-tutor\exported-zips\`

**Step 1**: Create new API endpoint `D:\projects\OpenMAIC\app\api\classroom\list-filesystem\route.ts`:
```typescript
import { type NextRequest } from 'next/server';
import { createLogger } from '@/lib/logger';
import { promises as fs } from 'fs';
import path from 'path';

const log = createLogger('ListClassroomFilesystem');

export async function GET(request: NextRequest) {
  try {
    const classroomsDir = path.join(process.cwd(), 'data', 'classrooms');
    try {
      await fs.access(classroomsDir);
    } catch {
      return Response.json({ classrooms: [] });
    }
    const files = await fs.readdir(classroomsDir);
    const jsonFiles = files.filter(f => f.endsWith('.json'));
    const classrooms = [];
    for (const jsonFile of jsonFiles) {
      try {
        const filePath = path.join(classroomsDir, jsonFile);
        const content = await fs.readFile(filePath, 'utf-8');
        const data = JSON.parse(content);
        classrooms.push({
          id: data.id || jsonFile.replace('.json', ''),
          name: data.stage?.name || 'Untitled',
          description: data.stage?.description,
          sceneCount: data.scenes?.length || 0,
          createdAt: data.stage?.createdAt || Date.now(),
          updatedAt: data.stage?.updatedAt || Date.now(),
        });
      } catch (error) {
        log.warn(`Failed to read classroom file ${jsonFile}:`, error);
      }
    }
    return Response.json({ classrooms });
  } catch (error) {
    log.error('Failed to list classroom files:', error);
    return Response.json({ classrooms: [], error: String(error) }, { status: 500 });
  }
}
```

**Step 2**: Create file endpoint `D:\projects\OpenMAIC\app\api\classroom\get-file\route.ts`:
```typescript
import { type NextRequest } from 'next/server';
import { readClassroom, isValidClassroomId } from '@/lib/server/classroom-storage';
import { createLogger } from '@/lib/logger';
import { promises as fs } from 'fs';
import path from 'path';

const log = createLogger('GetClassroomFile');

export async function GET(request: NextRequest) {
  try {
    const id = request.nextUrl.searchParams.get('id');
    if (!id) return Response.json({ error: 'Missing parameter: id' }, { status: 400 });
    if (!isValidClassroomId(id)) return Response.json({ error: 'Invalid classroom id' }, { status: 400 });

    // Try file system first
    try {
      const classroomsDir = path.join(process.cwd(), 'data', 'classrooms');
      const filePath = path.join(classroomsDir, `${id}.json`);
      const content = await fs.readFile(filePath, 'utf-8');
      const data = JSON.parse(content);
      return Response.json({ classroom: data });
    } catch (fileError) {
      // File not found, try classroom-storage
      const classroom = await readClassroom(id);
      if (!classroom) return Response.json({ error: 'Classroom not found' }, { status: 404 });
      return Response.json({ classroom });
    }
  } catch (error) {
    log.error('Failed to get classroom file:', error);
    return Response.json({ error: String(error) }, { status: 500 });
  }
}
```

**Step 3**: Modify `D:\projects\OpenMAIC\lib\utils\stage-storage.ts` `listStages()` function to also read from file system:

```typescript
export async function listStages(): Promise<StageListItem[]> {
  try {
    // 1. Read from IndexedDB (manually created courses)
    const stages = await db.stages.orderBy('updatedAt').reverse().toArray();
    const stageList: StageListItem[] = await Promise.all(
      stages.map(async (stage) => {
        const sceneCount = await db.scenes.where('stageId').equals(stage.id).count();
        return {
          id: stage.id, name: stage.name, description: stage.description,
          sceneCount, createdAt: stage.createdAt, updatedAt: stage.updatedAt,
          interactiveMode: stage.interactiveMode, taskEngineMode: stage.taskEngineMode,
        };
      }),
    );

    // 2. Read from file system (API generated courses)
    try {
      const response = await fetch('/api/classroom/list-filesystem');
      if (response.ok) {
        const fileClassrooms = await response.json();
        for (const fc of fileClassrooms.classrooms || []) {
          const existing = stageList.find(s => s.id === fc.id);
          if (!existing) {
            stageList.push({
              id: fc.id, name: fc.name, description: fc.description,
              sceneCount: fc.sceneCount, createdAt: fc.createdAt, updatedAt: fc.updatedAt,
              interactiveMode: undefined, taskEngineMode: undefined,
            });
          }
        }
      }
    } catch (e) {
      // File system read failure doesn't affect main flow
    }

    // Sort by updatedAt
    stageList.sort((a, b) => b.updatedAt - a.updatedAt);
    return stageList;
  } catch (error) {
    log.error('Failed to list stages:', error);
    return [];
  }
}
```

## Limitations

- **Read-only**: The file system approach only shows courses; clicking into a course uses the existing API to read from `classroom-storage.ts`, which may not have the file system data. The classrom detail page works because it uses different APIs.
- **Edit/Delete**: Cannot edit or delete file system courses from the UI; only IndexedDB courses can be managed.
- **Thumbnails**: Thumbnails may not display correctly for file system courses (the `getFirstSlideByStages` modification helps but not perfect).
