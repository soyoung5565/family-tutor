# Open Design 表单交互流程（2026-07-10 实证）

## 生成设计时的表单确认

Open Design 在收到设计需求后会弹出确认表单，需要选择或填写以下信息：

### 表单字段

| 字段 | 类型 | 推荐选择 |
|------|------|---------|
| 我们要做什么？ | 单选 | **Prototype**（原型） |
| 目标平台 | 单选 | **响应式网页** |
| 目标用户 | 文本 | 如"小学六年级学生，语文课后测验" |
| 品牌背景 | 单选 | **帮我选一个方向** |
| 大概需要多少内容？ | 文本 | 如"8道选择题 + 2道简答题，含结果页和知识点分析" |
| 还有什么需要知道的吗？ | 文本 | 可留空 |

### 操作流程

1. 输入设计需求 → 点"发送"
2. Open Design 弹出表单
3. 填写表单（或点"一键跳过"跳过所有问题）
4. 点"继续"或等待倒计时结束（约10分钟）
5. Open Design 开始生成（1-3分钟）
6. 生成完成后，文件路径显示在聊天界面（"写入 D:\\...\\index.html · N 行"）

### 快捷操作

- **一键跳过**：跳过所有表单问题，直接用默认值生成
- **继续**：确认当前填写的内容，进入下一步
- **生成产物**：跳过所有确认，直接开始生成

## 生成后必须做的事

1. **复制生成文件到项目目录**：
   ```bash
   cp "D:/projects/open-design/.od/projects/<project-id>/index.html" "D:/projects/family-tutor/quiz.html"
   ```

2. **添加后端同步代码**（Open Design 生成的页面不包含同步代码）：
   - 参考 `references/quiz-sync-code-template.md`
   - 在 submit 事件处理函数末尾添加 sync 代码

3. **替换示例题目为实际测验题**：
   - Open Design 生成的是示例题目（如编程基础题）
   - 需要替换为实际的测验题数据

4. **自动打开页面**：
   ```bash
   cmd.exe /c "start D:\projects\family-tutor\quiz.html"
   ```

## 注意事项

- Open Design 用 MIMO 模型生成时较慢（1-3分钟）
- 如果卡在"思考中"超过3分钟，可能是模型响应慢
- 生成效果不满意时，可以重新输入不同的提示词再生成一次
- **不要手写 CSS 替代**（用户明确要求必须用 Open Design）
