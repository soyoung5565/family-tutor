# 家庭教师系统 · AI Family Tutor

> 面向小学三科（数学 / 语文 / 英语）的 AI 教学系统：**按知识点出卷 → 作业批改 → 错题微课堂** 的完整学习闭环。
> *An end-to-end AI tutoring system: knowledge-point based exam generation, homework grading, and auto-generated remedial micro-lessons.*

**题库规模：12,269 题 · 全部完成知识点归属 · 真实教学场景持续运行中**

## 🎯 系统是什么

这不是一个"题库文件"，而是一套**真实运行中的教学系统**：为六年级学生提供每天的学习-练习-批改-补弱闭环。从教材知识点图谱出发，自动出卷、批改作业、把错题变成"微课堂"，并持续追踪知识点的掌握情况。

```
教材知识点图谱 → 按知识点出卷 → 学生作答 → AI 批改（两阶段）
     ↑                                            ↓
掌握情况更新 ← 错题微课堂（AI 生成课堂）← 错题归因入库
```

## ✨ 核心设计

### 1. 两阶段批改（教育理念：先让学生自己找错）
- **第一阶段**：只告诉学生"第几题错了"，不给答案、不给解法、不给错因
- **第二阶段**：学生自己订正后，只对"仍然错"的题给出正确答案 + 微课堂
- 一上来给答案等于替学生做作业——系统设计上就拒绝这样。

### 2. 不信赖字迹的批改流水线（防 OCR 幻觉）
批改质量实验发现：低分辨率下 OCR 会"用语言先验补全成通顺正确的版本"（即使不给它标准答案，它也会写出标准答案），导致批改失真。因此设计了独立校验流程：

1. vision **只看题目文字**（不看学生答案）
2. LLM **独立解题**（不看学生答案）→ 标准答案 + 解法
3. vision **提取学生答案**（带 confidence 标记）
4. 对比判定：错 → 归因 → 入库

> 结论性实验（含模型盲提取对照）见 [`文档/批改实验/`](文档/批改实验/)

### 3. 题库建设流水线（12269 题怎么来的）
多来源采集 + AI 提取 + **多模型投票评审**：
- 网页题库爬取（学科网 / 21世纪教育网 / 51教习网）→ 结构化提取 → 入库
- 每题经**多模型投票**：知识点归属、难度、跨册适用性、超纲检测
- 自检标记（`self_review`：kp_match / out_of_scope / passed）随题存储
- 深圳本地题优先（对应教材版本度最高）

### 4. 错题 → 微课堂
错题自动生成"错题讲解课堂"，白板逐步拆解思路，不做开场总结——每道错题独立成块。

生成过程走 HTTP 接口调用一个独立的多智能体课堂引擎（`/api/generate-classroom`）：我把错题清单 + 严格不超纲的约束文本提交给它，轮询任务完成后取回课堂 JSON，再跑一遍**自检脚本**（`verify-micro-lesson.py`）验证生成结果符合我们的知识点范围要求。

**这条边界要说明白**：课堂引擎本身是别人的开源项目（[THU-MAIC/OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)，MIT）；**本仓库自己的部分是**——出卷、批改、归因、知识点图谱、题库建设流水线、约束文本构造、生成结果自检这一整条教学闭环。

## 🔧 技术栈

- **语言**：Python（流水线）、HTML/JS（练习站）
- **AI 能力**：多模态 LLM（题目提取/批改）、OCR、TTS（语音讲解）
- **工程**：多模型投票评审、断点续跑、批量管线、任务看门狗、错题归因入库

## 📖 使用方式

系统的运行依赖 AI 助手（agent）编排，核心入口：

```bash
# 按知识点出卷（示例：数学 u1.k1 抽 5 题）
python 脚本/generate-exam.py --subject 数学 --kp u1.k1 --count 5

# 批改作业（学生作业照片 → 两阶段批改）
python 脚本/grade-mistake.py <作业图片路径>

# 错题清单 → 生成微课堂 → 自检
python 脚本/micro-lesson.py --wrong-list <错题清单>
python 脚本/verify-micro-lesson.py <课堂JSON>

# 每周学习计划（复习 → 补漏 → 预习 三相位）
python 脚本/generate-weekly-plan.py
```

详细文档见 [`文档/系统说明.md`](文档/系统说明.md) 与 [`文档/流程结构.md`](文档/流程结构.md)。
