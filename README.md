## 一、快速上手

### 场景 1：出一份练习卷

按知识点抽题，例如「数学 u1.k1（分数混合运算）」抽 5 题：

```python
import json, random
from pathlib import Path

SUBJ, KP, N = '数学', 'u1.k1', 5
f = Path(f'题库/{SUBJ}/测验/{KP.split(".")[0]}/{KP}.json')
qs = [q for q in json.loads(f.read_text(encoding='utf-8'))
      if q.get('kp_id') == KP and q.get('stem')
      and not (q.get('self_review') or {}).get('out_of_scope')]
paper = random.sample(qs, min(N, len(qs)))
```

**出卷必做过滤**：
- `out_of_scope` 为 false（排除超纲题）
- `enabled` 不为 false（排除被禁用题）
- `stem` 存在（有题干）

**优先级**：**深圳本地题**（qid 含 `szns`，74 道）**最高优先**，其次普通题库题。

### 场景 2：批改学生作业（**两阶段，务必按此走**）

```
学生发作业图片
      ↓
【第一阶段】只告诉学生「第几题错了」
      ↓   ⚠️ 不给答案！不给解法！不给错因！
学生自己订正 → 重发图片
      ↓
【第二阶段】只对**仍然错**的题：给正确答案 + 微课堂
```

**第一阶段输出就是一段纯文字**（方便直接粘微信）：
```
你的作业里第 3 题和第 7 题错了，请先自己订正一下。
```

**为什么这样设计**：先让学生自己找错、自己改，才有真正的学习效果；一上来给答案等于替学生做。

## 三、题库数据格式

每个 `{kp}.json` 是一个题目数组：

```json
{
  "qid": "数学_u1.k1_zxxk_53996783_002",
  "subject": "数学",
  "kp_id": "u1.k1",
  "unit_id": "u1",
  "difficulty": "易",
  "type": "填空题",
  "stem": "□-□÷□应先算（）法，再算（）法，结果是（）。",
  "options": null,
  "answer": "略",
  "self_review": {
    "kp_match": true,
    "out_of_scope": false,
    "stem_clear": true,
    "age_appropriate": true
  },
  "enabled": true,
  "use_count": 0
}
```

**关键字段**：
| 字段 | 用途 |
|---|---|
| `kp_id` | 知识点编号（**100% 已标注**，可放心按 KP 出卷）|
| `difficulty` | 易 / 中 / 难 |
| `answer` | 答案（**97.3% 有答案**）|
| `self_review.out_of_scope` | **出卷必须过滤掉 true 的** |
| `enabled` | false 表示已禁用 |
| `use_count` | 已使用次数（可用于避免重复出题）|

## 四、脚本一览

| 脚本 | 用途 |
|---|---|
| `generate-exam.py` | **出卷** |
| `quiz-bank-search.py` | 题库搜索（按关键词/KP 找题）|
| `grade.py` | 批改 |
| `grade-mistake.py` | **错题批改**（看题不看学生答案 → 独立解题 → 再比对）|
| `wrong-list.py` | **第一阶段**：生成「哪题错了」纯文字清单（自动剔除答案字段）|
| `collect-corrections.py` | 学生订正后再批（对比两次）|
| `micro-lesson.py` | **微课堂**（针对错题生成讲解）|
| `verify-micro-lesson.py` | 微课质量检查 |
| `classify-homework.py` | 作业分类 |
| `ocr-jpg-exam.py` | 试卷图片 OCR |
| `init-learning-state.py` | 初始化学习状态 |

**批改脚本的设计要点**（`grade-mistake.py`）：
1. vision 只看题目文字（**不看学生答案**）
2. LLM 独立解题 → 标准答案
3. 再提取学生答案
4. 比对 → 判定对错
5. 错题写入 `错题集/`

> 为什么先不看学生答案：避免被学生的错误解法带偏。

## 五、学习状态与规划

- **`文档/学习规划.md`** — 学期总览、每周计划（数学 61 KP / 语文 54 KP / 英语 26 KP）
- **`文档/学习状态.json`** — 当前进度、错题累计、薄弱知识点
- **`题库/{科目}/知识点及掌握情况/{kp}.json`** — 每个知识点的掌握度

**查漏补缺闭环**：
```
作业批改 → 记录错题 → 更新 KP 掌握度 → 找出薄弱 KP
                                              ↓
                          针对性出题练习 ← 生成微课堂
```
